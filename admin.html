Cadastrar jogo

Preencha os dados de um jogo que você tem direito de distribuir. Depois exporte o catálogo atualizado e publique a alteração no GitHub.

Importante: este painel prepara o catálogo no seu navegador; ele não envia arquivos nem publica sozinho. Para que todos vejam o jogo, o arquivo precisa estar hospedado em um endereço público e você precisa atualizar catalog.json no repositório. Cadastre somente jogos homebrew, de domínio público, próprios ou com autorização verificável para distribuição pública. Não use apenas uma autorização presumida.
O arquivo precisa estar publicado. Para arquivos no repositório, envie-os primeiro para a pasta games/ e use um link público adequado.

Publicar para todos

  1. Se o arquivo do jogo ainda não estiver hospedado, envie-o para um serviço público ou para a pasta games/ do repositório, respeitando o limite de tamanho do GitHub.
  2. Clique em Exportar catalog.json para baixar o catálogo atualizado.
  3. Abra catalog.json no GitHub, substitua o conteúdo pelo arquivo exportado e confirme o commit na branch gh-pages.
  4. Após a publicação do GitHub Pages, atualize a biblioteca. O jogo aparecerá para todos os visitantes.

O formulário guarda alterações apenas nesta sessão até você exportar e enviar o arquivo atualizado ao GitHub. Não coloque tokens ou senhas do GitHub neste site.
